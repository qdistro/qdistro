# Security reporting

Please report suspected vulnerabilities privately to **jan@kotek.net**.
Do not publish vulnerability details in a public issue.

If GitHub private vulnerability reporting is available on this repository,
you may also use **Security → Report a vulnerability**. Otherwise, use the
email address above.

Include the affected revision, relevant isolation configuration, attacker
prerequisites, a minimal reproducer, and expected versus observed behavior.
Remove credentials, private data, and other sensitive information from logs.

The supported security scope and limitations are described in the
[threat model](doc/threat-model.md). qdistro is pre-release; this policy does
not promise a response deadline or support for older releases.
