# Settings → System Monitor

What must be visible when this tab is open:

- Tab header text: "System Monitor" (i18n key `system-monitor.title`).
- Subtab bar with at least: "General" and "Thresholds".
- Display toggles for CPU / GPU / RAM / thermal stats.
- Threshold sliders (warning / critical levels).
- The standard left-side Settings tab strip is visible.
