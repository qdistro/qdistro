# Settings → OSD

What must be visible when this tab is open:

- Tab header text: "OSD" (i18n key `panels.osd.title`).
- Subtab bar with at least: "General" and "Events".
- A "Position" dropdown.
- An "Enabled" toggle.
- An "Always On Top" toggle.
- A "Background Opacity" slider.
- The standard left-side Settings tab strip is visible.
