# Settings → Hooks

What must be visible when this tab is open:

- Tab header text: "Hooks" (i18n key `panels.hooks.title`).
- Subtab bar with at least: "General" and "Hooks".
- A list / editor of hook entries (a hook fires a script on a shell event).
- Hook event labels (e.g. on-startup, on-suspend) visible somewhere on the page.
- The standard left-side Settings tab strip is visible.
