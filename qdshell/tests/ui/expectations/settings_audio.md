# Settings → Audio

What must be visible when this tab is open:

- Tab header text: "Audio" (i18n key `panels.audio.title`).
- Subtab bar with at least: "Volumes", "Devices", "Media", "Visualizer".
- A volume slider section (output / input / per-app) with numeric percent readouts.
- A device selector (output device dropdown or radio list).
- The standard left-side Settings tab strip is visible.
