# Panel: Audio

What must be visible when this panel is open:

- Header section showing an audio/speaker icon and the title "Audio" (i18n `panels.audio.title`).
- A close button (✕) in the top-right of the header.
- Tabs or sections for "Volumes" and "Devices".
- An output volume slider with a percentage readout and a mute control.
- An input volume slider with a percentage readout and a mute control.
- Per-application volume rows (if any apps are producing audio).
- An output device selector (radio list or dropdown) listing detected sinks.
- An input device selector (when input devices are present).
