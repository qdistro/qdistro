# Panel: Bluetooth

What must be visible when this panel is open:

- Header section showing a bluetooth icon ("bluetooth" when on, "bluetooth-off" when off) and the title "Bluetooth" (i18n `common.bluetooth`).
- A bluetooth enable/disable toggle in the header row.
- A header settings (gear) button.
- A close button (✕) in the top-right.
- A list of paired / connected devices when Bluetooth is on.
- When Bluetooth is off, a state message indicating it's disabled.
