# Panel: Launcher

What must be visible when this panel is open:

- A search input field at the top, with cursor focus.
- A results area showing matching applications or commands. Each result has an icon, a name, and an optional description / second-line metadata.
- A view-mode toggle (list vs grid) somewhere on the panel.
- A status / hint footer (may show modifier-key hints or current mode like `>clip`, `>cmd`, `>emoji`, `>win`, `>settings`).
- No standard header close button — Escape closes the launcher.
- When the search yields no matches, an empty/no-results state is shown.
