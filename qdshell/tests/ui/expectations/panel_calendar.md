# Panel: Clock / Calendar

What must be visible when this panel is open:

- A calendar header card showing the current month and year, with prev/next navigation arrows.
- A calendar month grid showing the days of the current month, with the current day highlighted. Week-number column may be visible depending on the `showWeekNumberInCalendar` setting.
- A weather card (visible only when `weatherEnabled`) showing the next ~5 days of forecast.
- This panel does NOT have a standard header bar or close button — it's a card stack.
