# Panel: Session Menu

What must be visible when this panel is open:

- A grid or row of power-action buttons. Each button has an icon and a label. Standard actions, whichever are enabled by config: Lock, Suspend, Hibernate, Reboot, Logout, Shutdown.
- If `largeButtonsStyle` is on, the panel fills the screen with large buttons; otherwise it's a compact panel.
- A countdown timer appears when an action is armed; a stop / cancel button replaces the close button while a timer is running.
- The selected / focused button is visually highlighted.
- Keybind hint glyphs are visible on each button.
