# Settings → User Interface

What must be visible when this tab is open:

- Tab header text: "User Interface" (i18n key `panels.user-interface.title`).
- Subtab bar with at least: "Appearance", "Panels", "Screen Corners".
- Top-level toggles visible on the default subtab include: "Tooltips", "Box Border", "Shadows".
- A "Shadow Direction" dropdown.
- A "Scaling" slider with numeric readout.
- A "Box Border Radius" slider with numeric readout.
- The standard left-side Settings tab strip is visible.
