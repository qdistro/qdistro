# Settings → Lock Screen

What must be visible when this tab is open:

- Tab header text: "Lock Screen" (i18n key `panels.lock-screen.title`).
- Subtab bar with at least: "Appearance" and "Monitors".
- A clock-style selector (analog / digital / custom).
- Lock-behaviour toggles (e.g. "Lock on suspend", "Compact lock screen").

(The tab intentionally has no background-image selector — the lock screen
renders the desktop wallpaper; only clock style, format, blur/tint and
monitor selection are configurable.)
- The standard left-side Settings tab strip is visible.
