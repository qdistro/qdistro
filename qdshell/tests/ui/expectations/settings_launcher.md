# Settings → Launcher

What must be visible when this tab is open:

- Tab header text: "Launcher" (i18n key `panels.launcher.title`).
- Subtab bar with at least: "General", "Clipboard", "Execute".
- A "Position" dropdown.
- An "Overlay Layer" toggle.
- A "View Mode" dropdown (list / grid).
- The standard left-side Settings tab strip is visible.
