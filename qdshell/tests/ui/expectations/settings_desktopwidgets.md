# Settings → Desktop Widgets

What must be visible when this tab is open:

- Tab header text: "Desktop Widgets" (i18n key `panels.desktop-widgets.title`).
- A "Desktop Widgets Enabled" toggle near the top.
- An "Edit Mode" button.
- A per-monitor section (one block per attached display) showing the widget editor for that monitor.
- The standard left-side Settings tab strip is visible.
