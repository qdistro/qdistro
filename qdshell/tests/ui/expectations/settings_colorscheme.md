# Settings → Color Scheme

What must be visible when this tab is open:

- Tab header text: "Color Scheme" (i18n key `panels.color-scheme.title`).
- Subtab bar with at least: "Colors" and "Templates".
- A scheme picker / list of available color schemes.
- A palette display area showing color swatches.
- A download / fetch button for new schemes.
- The standard left-side Settings tab strip is visible.
