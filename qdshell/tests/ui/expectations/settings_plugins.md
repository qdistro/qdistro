# Settings → Plugins

What must be visible when this tab is open:

- Tab header text: "Plugins" (i18n key `panels.plugins.title`).
- Subtab bar with at least: "Installed", "Available", "Sources".
- A plugin list with enable/disable toggles per row.
- Install / remove buttons.
- A repository / sources list.
- The standard left-side Settings tab strip is visible.
