# Settings → General

What must be visible when this tab is open:

- Tab header text: "General" (i18n key `common.general`).
- A horizontal subtab bar containing at least: "Basics" and "Keybinds".
- A profile section with profile-related controls.
- A font configuration section with at least:
  - "Default Font" selector (dropdown / font picker).
  - "Monospace Font" selector.
  - "Font Scale" slider with a numeric percentage readout.
  - "Monospace Scale" slider.
- Scrolling-behaviour toggles: "Reverse Scrolling" and "Smooth Scrolling".
- The standard left-side Settings tab strip is visible.
